Effective 10-23-26. This policy describes how CRMExtender handles the data it receives from Google accounts.

1. Who operates CRMExtender

CRMExtender is open-source software. Each copy is installed and operated by one person on that person's own computer. This instance is operated by Doug Bower for his own mail accounts only. No one else can sign in to it, and it is not offered as a service to the public.

2. What Google data it accesses

With the account holder's consent through Google sign-in, CRMExtender requests these permissions:

  • Gmail: read messages, threads and labels; change labels, read state and other message flags; send messages. Google scopes: https://mail.google.com/, gmail.readonly, gmail.modify, gmail.send.
  • Google Contacts: read contact names, email addresses and contact groups. Scope: contacts.readonly.
  • Google Calendar: read calendar events. Scope: calendar.readonly.

3. How the data is used

CRMExtender copies the connected mailboxes, contacts and calendar events into a database on the operator's computer. It uses that copy to display mail, group messages into conversations, link messages to the people and companies involved, show calendar context beside those records, and carry out the operator's own actions: reply, send, archive, label, mark read, snooze and follow up. Nothing is used for advertising, profiling of third parties, or resale.

4. Where the data is stored

All mail, contact and calendar data is stored in a database file on the operator's own computer. Google sign-in tokens are stored as files on that same computer. CRMExtender runs no server of its own and uploads none of this data to any system operated by CRMExtender or its author.

5. Sharing with third parties

  • Anthropic. When the operator turns on conversation summaries, the text of a conversation (subject, sender, date and message body) is sent to Anthropic's API to produce a summary and classification. Anthropic's API terms govern that processing. This is the only transfer of Google user data to a third party.
  • Public web pages. To fill in company records, CRMExtender may fetch a company's public website. No Google user data is sent in those requests.

No Google user data is sold, shared with advertisers, or used to train general-purpose artificial intelligence models.

6. Retention and deletion

Data stays in the local database until the operator removes it. Disconnecting an account inside CRMExtender deletes that account's sign-in token, and the operator can delete the database file at any time. Access can also be revoked from the Google account's permissions page at myaccount.google.com/permissions, after which CRMExtender can no longer read or change anything in that account.

7. Google API Services User Data Policy

CRMExtender's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

8. Changes and contact

Changes to this policy are published on this page with a new revision number and date. Questions go to Doug Bower, doug@dougbower.com.
